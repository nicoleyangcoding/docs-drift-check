# Roadmap

Small, focused releases. Suggestions are welcome in [issues](https://github.com/nicoleyangcoding/docs-drift-check/issues).

## 1.1
- [ ] `require: all` per mapping, for areas where every listed doc must change
- [ ] `min-changed-lines` input, so one-line fixes don't trigger a reminder
- [ ] Link each doc in the comment to its file on the pull request's head branch

## 1.2
- [ ] `suggest` command: propose a starting `docs-map.yml` from folder and doc names
- [ ] Weekly report recipe: which areas drift most often
- [ ] Support a `CODEOWNERS`-style single-line syntax as an alternative to YAML

## Later
- [ ] Mention the code owners of the stale docs in the comment (opt-in)
